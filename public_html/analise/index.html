Exporte o resultado da sua query no Event Search em JSON, envie aqui e veja os eventos organizados para leitura humana: linha do tempo, árvore de processos e os pontos que merecem atenção.

O que vai ter

Linha do tempo

Os eventos em ordem, agrupados por minuto, para ver o que aconteceu antes e depois.

Árvore de processos

Quem criou quem, com linha de comando e usuário de cada processo.

Resumo do resultado

Hosts, usuários, domínios e IPs que mais aparecem, com contagem.

Pontos de atenção

Destaque para binários sem assinatura, pastas de usuário, comandos encodados e conexões externas.

Fica no seu navegador

O arquivo é lido no seu computador. Nada é enviado para o servidor do S1QLBR.

Como exportar (para já ir se preparando)

  1. Rode a query no Event Search do console.
  2. Use a opção de exportar resultados e escolha o formato JSON.
  3. Quando a página estiver pronta, é só arrastar o arquivo aqui.
