# S1QLBR — Identidade da marca

Decidido em 11/11/2026. Cor de destaque trocada de verde para roxo em 11/11/2026.

## Nome e domínio

| Item | Valor |
|---|---|
| Marca / nome do sistema | **S1QLBR** |
| Domínio oficial | **s1qlbr.com** (hospedado na HostGator, SSL via AutoSSL) |
| Descrição curta | Gerador de queries para threat hunting |
| Modelo | Gratuito |

**Observação:** "S1QL" é o nome da linguagem de consulta da SentinelOne. O projeto é gratuito, o que reduz o risco. Mesmo assim, use um logo próprio, sem cores ou símbolos da SentinelOne. No texto do site, prefira a forma descritiva "compatível com SentinelOne".

## Logo

**Conceito do ícone**
- **Cilindro de banco de dados:** a base de eventos.
- **Faixa roxa no meio do cilindro:** o registro que a query encontrou.
- **Lupa:** a consulta.

Nos favicons de 32 px e 16 px a lupa sai, para o ícone continuar legível.
